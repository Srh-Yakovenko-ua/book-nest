# Frontend: блок та issue cards

## Розміщення

Блок знаходиться у правому сайдбарі сторінки **«Черга читання»**.

Показувати максимум три issue items у порядку, який повернув backend.

## Header

```text
Перевірити порядок серій          3
```

Підзаголовок:

```text
Знайдено серії, де порядок читання може бути порушений
```

Якщо існує маршрут або модалка з усіма issues:

```text
Переглянути всі →
```

Не додавати dead link, якщо повного view ще немає; у межах цього повного функціоналу потрібно реалізувати доступний спосіб переглянути всі issues.

## Дані картки

Кожна картка показує:

- severity icon;
- назву серії;
- короткий заголовок проблеми;
- просте пояснення;
- проблемну книгу;
- попередню актуальну книгу, якщо є;
- current order;
- recommended order;
- основну дію;
- додаткові дозволені дії;
- «Залишити як є»;
- «Не перевіряти цю серію» у secondary/menu action.

Одна серія — одна картка, навіть якщо backend повертає `relatedProblems`.

## Тексти problem types

### `missing_previous_from_queue`

```text
Перед «{affectedBook}» ще не завершено «{previousBook}».
```

Primary CTA:

```text
Додати перед «{affectedBook}»
```

### `previous_book_after_later_book`

```text
«{previousBook}» має бути раніше за «{affectedBook}».
```

Primary CTA:

```text
Виправити порядок
```

### `multiple_previous_missing`

```text
Перед «{affectedBook}» залишилося {count} незакриті частини.
Наступна за порядком — «{previousBook}».
```

Primary CTA:

```text
Додати наступну книгу
```

Secondary CTA:

```text
Додати всі за порядком
```

### `previous_book_paused`

```text
Попередня частина ще не завершена.
«{previousBook}» на паузі, а «{affectedBook}» уже попереду.
```

Primary CTA:

```text
Повернутися до книги
```

### `current_reading_ahead_of_order`

```text
Поточне читання випереджає порядок серії.
Зараз читається «{affectedBook}», хоча «{previousBook}» ще не завершена.
```

Primary CTA:

```text
Відкрити попередню книгу
```

### Ownership-related

`previous_book_not_owned`:

```text
Попередньої частини немає у власній бібліотеці.
```

CTA: `Додати до «Хочу купити»`.

`previous_book_want_to_buy`:

```text
Попередня частина ще не придбана.
```

CTA: `Перейти до покупки`.

`previous_book_in_transit`:

```text
Попередня частина вже в дорозі.
```

CTA: `Переглянути замовлення`.

`previous_book_lent_out`:

```text
Попередня частина позичена комусь і зараз недоступна.
```

CTA: `Переглянути позику`.

### `multiple_books_out_of_order`

```text
У серії переплутано порядок.
```

Показати:

```text
Зараз: 3 → 2 → 4
Рекомендовано: 2 → 3 → 4
```

CTA: `Розташувати за порядком серії`.

## Візуальні правила

- Використати наявні sidebar/card компоненти та theme tokens.
- Використати наявну систему іконок; у проєкті — Lucide, не додавати іншу бібліотеку.
- Не створювати окрему палітру.
- Error/warning/info мають відрізнятися не лише кольором, а й іконкою та текстом.
- Назва серії — максимум 1 рядок із ellipsis.
- Назви книг — максимум 2 рядки.
- Повний текст доступний через наявний tooltip лише як доповнення.
- Картка має працювати у світлій і темній темах.
