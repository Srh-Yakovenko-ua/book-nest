# Backend roadmap

A living backlog of what the backend still lacks for production and what each item teaches. Built on 2026-08-27 from a full scan of the backend surface: 1360 files across `apps/api/src`, `apps/api/prisma`, `deploy/`, `.github/workflows` and `packages/shared/src`. Every row below was checked by a script that required two proofs per claim, a `file:line` showing what handles the concern today and a grep returning zero hits for the missing piece. 79 claims went in, 78 held, 1 was dropped (see the last section).

How to use it: pick a row, do it, tick the box and append the date and commit. A row marked with a PR number has an open pull request against `dev`; tick it when that PR merges. Do not reorder the blocks; the order is the recommendation. Sizes are rough: S is under half a day, M is one to two days, L is three or more.

Inventory at the time of the scan, all counted by command: 27 modules, 64 controllers, 280 HTTP routes, 88 services, 60 repositories, 12 hourly `@Cron` jobs, 10 BullMQ queues with 9 processors, 1 WebSocket gateway, 57 Prisma models, 96 migrations, 32 env variables, 317 test files over 881 source files.

## What is already solid

These were verified during the scan and need no work. Listed so nobody re-audits them.

- Login is timing-safe (`PasswordService.fakeCompare`, `auth.service.ts:53`), bcrypt cost 12 with a sha256 pre-digest that avoids the 72-byte truncation (`password.service.ts:5,24`).
- Reset and verification tokens are 32 random bytes stored as sha256 plus pepper, single-use, with TTL and a 60 s cooldown (`token.service.ts:82`, `password-reset.service.ts:58-68`).
- Refresh tokens rotate with reuse detection and a 10 s grace window (`session.service.ts:78-111`).
- Realtime handshake checks the bearer token and the Origin, caps connections per user, caps message size at 4 KB, disconnects on token expiry (`realtime.gateway.ts:49-190`).
- Uploads sniff MIME with `file-type`, cap at 20 MB, and sharp runs with `limitInputPixels: 25M`.
- JWT secrets are required with `min(32)` and have no default in prod; `trust proxy: 1` matches the single Caddy hop; Swagger is off in prod.
- Postgres pool has `statement_timeout` 30 s and `idle_in_transaction_session_timeout` 60 s (`prisma.service.ts:7-10`).
- `/api/metrics` is closed at the edge: Caddy answers 404 (`deploy/Caddyfile:10-13`).
- Money is `Decimal(10,2)`, every timestamp is `timestamptz`.
- CI: gitleaks blocks, four API test shards, migrations applied before tests.

## How this was verified

Four read-only scans, one per axis (operations, security, data layer, product), each returned findings with a `file:line` for what exists and a grep for what is absent. A single re-runnable script then re-executed both proofs for every claim; a claim survived only when the existence proof returned a line and the absence grep returned zero. Broad grep shapes caught three false drops on the first run (`/import` matched `importance.js`, `oauth` matched `toAuthorView`, `idempoten` matched test names) and one false keep (the product scan missed the reading-history tables).
