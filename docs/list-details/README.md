## Прийняті рішення

Зафіксовані відповіді на «Питання, які ще потрібно окремо обговорити» зі спеки (розділ §581+).
Кожне рішення далі вважається вимогою, а не пропозицією.

| № зі спеки        | Рішення                                                                                                                                                                                                                                                                                                                          |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| §1 Шапка          | Колаж **із 4 обкладинок** (`previewCovers` уже віддає рівно 4). Назва · опис · **тільки дата оновлення** · `Додати книги` (primary) · меню `•••`. Кількість книг у шапці **не дублюємо** — вона у картці «Усього книг». Окремої кнопки `Редагувати` немає, лише в меню.                                                          |
| §2 / §3 Картки    | Один шаблон із трьома слотами (бейдж читання, бейдж володіння, один CTA). Вісім «станів картки» — це **мапа `readingStatus → CTA`**, а не вісім компонентів.                                                                                                                                                                     |
| §4 Позиція        | Позиція вже існує для всіх списків (`BookListItem.position`, NOT NULL). `Позиція в списку` — сортування за замовчуванням. Окремого налаштування «Показувати нумерацію» **не буде**: номер показується тоді й лише тоді, коли активне сортування `position`. Нові книги — в кінець. DnD блокується при активному пошуку/фільтрах. |
| §5 Додавання книг | Виключення вже доданих книг — **на бекенді** (`notInList`), не на фронті. Вікно лишається відкритим після додавання. `Вибрати всі` = тільки поточна сторінка, підписано явно.                                                                                                                                                    |
| §6 Масові дії     | Перша реалізація: прибрати зі списку · додати до іншого списку · додати в чергу · улюблені. Вибір скидається при зміні фільтра й при переході на наступну сторінку. Підтвердження перед масовим прибиранням зі списку **не потрібне** — достатньо toast із `Скасувати`.                                                          |
| §7 Меню списку    | `Редагувати` · `Дублювати` · `Видалити`. Експорт і копіювання переліку — пізніше, на фронті. `Створити ціль` у меню **не дублюється** (вона в правому барі).                                                                                                                                                                     |
| §8 Порожні стани  | Без «швидких сценаріїв» (додати непрочитані / скопіювати з іншого списку) — кожен із них тягне окремий ендпоїнт.                                                                                                                                                                                                                 |
| §9 Пагінація      | `Показати ще`, `pageSize = 24` (як у бібліотеці). URL при довантаженні не змінюється. Статистика не залежить від пагінації — вона приходить з `/overview`.                                                                                                                                                                       |
| §10 Мобільна      | `Зараз читаються` стоїть **вище** статкарток. `Про добірку` і `Спільні книги` — згортувані, згорнуті за замовчуванням. Фільтри — bottom sheet. Зміна порядку — окремий режим `Редагувати порядок`, без long-press DnD у скролі.                                                                                                  |
| §11 Optimistic    | Оптимістично — тільки улюблене й `↑ ↓`. Решта (видалення, масові дії, додавання) — pending-стан + інвалідація, бо тягнуть за собою `/overview`, `statusCounts`, `/facets` і `/related`.                                                                                                                                          |
| §12 Налаштування  | Фільтри, сортування, пошук, таб, режим перегляду → **URL query params** через `nuqs`, точно як у «Моїй бібліотеці». Сортування «окремо для кожного списку» **не зберігаємо**.                                                                                                                                                    |
| §13 Доступність   | Кнопки `Перемістити вище/нижче` — **завжди в DOM** (у меню `•••`), вони і є доступний шлях. Після переміщення — `aria-live` повідомлення.                                                                                                                                                                                        |
| §14 Сітка         | `lg:grid-cols-[minmax(0,1fr)_19rem]`, sticky-бар. На tablet (<1280 px) бар переноситься вниз — sticky на планшеті немає.                                                                                                                                                                                                         |

## Порядок робіт

Етапи впорядковані так, щоб кожен давав робочу сторінку й міг бути змерджений окремо.

| Етап       | Зміст                                                                                          | Міграція |
| ---------- | ---------------------------------------------------------------------------------------------- | -------- |
| **1**      | Фільтри, швидкі таби з лічильниками, фасети, два нових сортування                              | ні       |
| **2**      | `GET /api/lists/:listId/overview` → 4 статкартки + `Про добірку` + `Зараз читаються`           | ні       |
| **3**      | `GET /api/lists/:listId/related` → блок «Спільні книги з іншими списками»                      | ні       |
| **4**      | `notInList`, масове прибирання, дублювання списку, `previewCovers` у деталях                   | ні       |
| **5**      | Drag-and-drop (`kind: "index"`), щільна перенумерація, режим списку                            | ні       |
| **6**      | Другий етап зі спеки: `Непрочитані/Прочитані спочатку`, рік видання, фільтри оцінки й сторінок | ні       |
| **окремо** | [Читацькі цілі](../reading-goals/)                                                             | **так**  |

Уся сторінка деталей списку реалізовна **без жодної зміни схеми БД**. Єдина міграція в усьому
обсязі — це `ReadingGoal`, і вона живе в окремій фічі.

## Що вже готове й переробці не підлягає

- `GET /api/lists/:listId` — шапка + пагінована сторінка книг, серверні пошук/сорт/пагінація.
- `ListBookView` = повний `BookView` + `position`: статуси, формати, жанри, рейтинг, прогрес,
  чергу, улюблене, серію, обкладинку, `lists[]`. Картки книг **не потребують жодного нового поля**.
- 9 сортувань із 13; `nulls: "last"` в обох напрямках для рейтингу/сторінок/року вже правильний.
- Мутації членства: bulk-додавання, прибирання з перенумерацією, `↑ ↓` — усе під advisory-lock.
- Масові дії над книгами: `favorite`, `reading-status`, `ownership-status`, `pages-count`,
  `tags`, `lists`, `reading-queue`, `delete` (`apps/api/src/modules/books/api/bulk-books.controller.ts`).
- Soft-delete / trash / restore списку, `GET /api/lists/summary`.
