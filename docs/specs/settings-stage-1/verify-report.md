## Drift

Everything outside the tasks is justified.

- `components/test-notification-block.tsx`, `timezone-row.tsx` and `week-start-row.tsx` split out code that T10 to T15 asked for.
- `model/weekday-preview.ts` with its test serves T15.
- `components/ui/segmented.tsx` forwards `aria-describedby`, `aria-disabled` and `ref` for the week-start lock and the hint. The props are optional, so existing callers are unaffected, and T22's blast radius should include this file.
- `model/timezone-city-names.ts` is generated from CLDR 48.2 (T3, D1). It records no provenance in code, so the PR body should carry it.
- `notification-settings-section.tsx:124-132, 160-163, 177-180` block typeahead on the closed lead-days select and keep it from opening while it saves. Both serve T11's one PATCH per pick and the D4 lock (`qa.md:17`).
- `test-notification-block.tsx` uses `aria-disabled` and a spinner rather than `Button loading`. `loading` sets `disabled` (`components/ui/button.tsx:77`), which would drop keyboard focus.
