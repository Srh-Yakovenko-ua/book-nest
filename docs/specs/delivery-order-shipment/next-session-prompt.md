# Промпт для наступної сесії

Вставити в Claude Code на машині, де є локальний Postgres.

---

Продовжуємо бекенд-рефакторинг доставок у цьому репозиторії. Гілка `refactor/delivery-order-shipment`, вона вже запушена.

Спочатку прочитай `docs/specs/delivery-order-shipment/handoff-2026-08-13.md` — там стан справ на момент передачі, шість підходів, які вже пробували й відкинули, і живі пастки середовища. Потім `docs/specs/delivery-order-shipment/tasks.json` (план, статуси, критерії готовності, чотирнадцять ухвалених рішень) і `docs/transit.md` (специфікація, кожна задача посилається на її розділи за номером).

Суть рефакторингу: замість однієї доставки на книгу тепер `BookOrder → BookOrderItem → Shipment`. Сім зрізів позаду, 52 із 76 задач. Твій зріз — тести: T51-T58 і T67.

Порядок дій:

1. `git checkout refactor/delivery-order-shipment && pnpm install`
2. `pnpm --filter @app/shared build` — обовʼязково: пакет споживається через `dist`, інакше vitest не побачить нових експортів
3. `pnpm db:up`
4. Один прогін `pnpm test`. Це розвідка, а не перевірка: усі інтеграційні тести зі зрізів 5-7 писались без локальної бази і жодного разу не запускались. Зафіксуй, що падає, і покажи мені перелік до того, як щось правити.

Жорсткі обмеження:

- Не зливай гілку в `dev` і не відкривай PR без моєї згоди. Записи вже йдуть у нові таблиці, а старі сторінки доставок читають стару — дані розійдуться.
- Не чіпай `packages/shared` і `apps/web`. Видалення старих контрактів (T12) і перегенерація клієнта (T50) ламають фронт на рівні компіляції, тож вони йдуть тільки разом із міграцією фронтенду.
- Не роби `DROP TABLE book_deliveries`. Це окремий зріз після тестів.
- Node 24 обовʼязково, інакше ESLint падає.

Три питання чекають на моє рішення і змінюють обсяг — не вгадуй, спитай: чи лишаємо префікс `books/` у read-маршрутах, чи має посилка автоматично ставати отриманою після останньої позиції, і чи прийнятне повторне нагадування на книгу після переходу на нову модель.

Закінчивши тестовий зріз, віддай його на `code-reviewer` перед комітом.
