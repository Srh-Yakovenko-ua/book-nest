**Mode decision.** `bookId` comes from the URL via `useQueryState("bookId")` (`character-edit-page.tsx:50`). Details are fetched with `includeHiddenProfiles`, all reveal keys and `contextBookId` (`:51-56`). `appearance = appearances.find(bookId)` (`:68-69`); `contextBookId` is `bookId` only when that appearance exists, else `null` (`:75`). `contextBookId === null` is global mode: only `CharacterGlobalSection` and `CharacterAliasesSection` (global group) render (`:185-220`), and `bookDirty` is forced false (`:130-132`). A `bookId` without an appearance silently becomes global mode (C30); this stays.

**Save.** `globalDirty` / `bookDirty` compare mapped payloads against a `baseline` state (`:99-133`). Submit PATCHes global first, then book, updating the baseline per scope, so a failed book PATCH retries only the book scope (`:153-181`). Masked fields (`appearance.hiddenFields`) are dropped from the book payload (`character-edit-form.ts:228`, `:343-345`).

**Inheritance and portrait.** `BookCharacterInheritanceSection` (`character-edit-sections.tsx:63-151`) renders display name, portrait, species override (each behind `MaskedOr`, which swaps a masked field for a `CharacterSpoilerField` placeholder, `:629-647`) and attitude (not maskable). `null` means inherit. Text/select fields show the global value read-only with an "override" link that prefills from global; overriding swaps in an input with a "use main value" reset. The portrait goes through `InheritedImageField` → `CharacterImageField`: inherited shows the global avatar and "Вибрати зображення для цієї книги"; overridden shows the saved portrait plus "Замінити зображення" and "Використовувати основне зображення". Upload posts `kind: "avatar"` media, stores the URL in the image field's own state and the id in `book.portraitMediaId`. The page never sees the uploaded URL, and reset drops the preview to the initial letter (C40).
