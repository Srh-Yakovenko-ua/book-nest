## Canonical populations

- **Active Book:** `books.deleted_at IS NULL`, scoped to the user. Sources: `SOFT_DELETE_SCOPE.active` (`core/database/soft-delete.ts:4`), the genre summary library count (`genre-stats.repository.ts:175-176`), the current tag book count (`tags.repository.ts:69`), and the trash-isolation test (`book-trash-isolation.controller.test.ts:149-150`). Book has no `archivedAt`. Wishlist books are included, as in the genre summary.
- **Visible Character:** `characters.deleted_at IS NULL AND archived_at IS NULL` is the default population of the global list (`global-character-filter.ts:17`, `characters.repository.ts:1026`). By default the list also drops `hide_profile_as_spoiler = true` (`global-character-filter.ts:27`, `characters.repository.ts:1031`). Whether that spoiler mask counts toward "visible" is open as D1.

## Tag.type invariant

- Local `booknest_dev` (docker `booknest-local-db`, user from the container's `POSTGRES_USER`) was queried read-only: 0 tags, so it proves nothing.
- The dev DB (`apps/api/.env.dev` points at `localhost:5532`) refused the connection because the tunnel is not open. To check it, open the tunnel and run `SELECT type, count(*) FROM tags GROUP BY type;` and the same query for `color`. Do not use `.env.prod*`.
- No code path can write a non-canonical type, so the risk is limited to manual SQL. D2 recommends an idempotent normalizing migration so the check does not depend on reaching each environment.
