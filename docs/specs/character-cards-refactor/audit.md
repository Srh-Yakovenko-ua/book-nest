## 2. What changes the plan

1. **C34.** A generic multi-line clamp hook already exists (`useIsTextClamped`) and is unit-tested. Do not write a new local helper. Reuse the hook, and use the TagNameCapsule controlled-open pattern for the tooltip.
2. **C8 / C39 / C40.** A Storybook play function that clicks through `storybook/test`'s `userEvent` cannot reproduce the original bug, because it has no real `:hover` and no hit-testing. It would pass before the fix, and CI never runs it anyway. The browser proof needs real pointer input and a red run against the unfixed code. See D3.
3. **C5.** The UI/CharacterCard stories are a third consumer. Their play function must stay green under `test:storybook`.
4. **C44.** The name link's accessible name decides whether 38 existing test lookups survive. See D2.
5. **C47.** Where the tooltip trigger goes is constrained by the stretched-link geometry. The optional secondary-name tooltip does not fit naturally. See D8.
6. **C28.** There is no unlink icon. The unlink item keeps `link`, and no icon is added.
