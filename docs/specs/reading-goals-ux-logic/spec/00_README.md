## Важливо

Схвалено **візуальний напрямок**, а не піксельну точність автоматично згенерованих макетів. У макетах можливі спрощення або неправильні числові/текстові дані. **Якщо між PNG і цим ТЗ виникає суперечність, пріоритет має ТЗ, доменні правила, доступність та фактичний API.**

Цей пакет **не означає, що код уже змінено**. До запуску `START_CLAUDE_CODE.md` потрібно лише переглянути ТЗ. Реалізація має відбуватися в окремій гілці, без worktree, якщо стан репозиторію дозволяє.
