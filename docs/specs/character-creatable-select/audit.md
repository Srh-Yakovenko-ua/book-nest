## 2. What changes scope

- **Create mode does not exist for these fields (C1).** The work is the edit page only, covering the book-scoped Status and the global Gender. «створення/редагування» collapses to «редагування».
- **Payload clearing is already done (C7).** `character-edit-form.ts` needs no diff. The new requirement is that the form state holds `""` after a standard pick. Only a component-level `onChange` assertion can prove that, because the payload is already `null` either way.
- **Labels must go through cmdk (C25).** The two fields cannot keep `LabeledField`/`<Label htmlFor>`. They follow the role-picker caption pattern. The existing test `:706-714` keeps the name «Гендер» honest.
- **Legacy sentinels without text are real for status (C23).** The display fallback (D4) is required, not hypothetical.
- **Escape/revert and focus behaviour have no precedent in the repo (C10, C13).** D2 decides them before any code.
