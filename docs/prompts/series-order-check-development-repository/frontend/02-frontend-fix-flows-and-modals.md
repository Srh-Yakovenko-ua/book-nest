# Frontend: fix flows та модалки

## Загальне правило

Frontend не змінює чергу локально на основі власних розрахунків.

Flow:

```text
натискання CTA
→ запит preview
→ модалка before/after
→ підтвердження
→ apply з expectedQueueVersion
→ invalidation/refetch
```

## Модалка preview

Має показувати:

- назву серії;
- причину конфлікту;
- поточний порядок;
- новий порядок;
- книги, які будуть додані;
- книги, які перемістяться;
- старі та нові позиції;
- кількість зміщених сторонніх книг;
- попередження про queue limit або інші обмеження, якщо backend їх повернув.

Кнопки:

```text
Скасувати
Підтвердити дію
```

Для reorder label може бути:

```text
Виправити порядок
```

Для insert:

```text
Додати й виправити
```

## Reorder series slots

Приклад preview:

```text
Виправити порядок серії?

Зараз:
3. «Спіймана»
8. «Правильне рішення»

Після виправлення:
3. «Правильне рішення»
8. «Спіймана»

Інші книги залишаться на своїх позиціях.
```

## Додавання однієї книги

```text
«Книга 2» буде додана на позицію 4.
«Книга 3» і всі книги нижче змістяться на одну позицію.
```

## Додавання всіх відсутніх книг

Показати повний список:

```text
Буде додано:
- Книга 2
- Книга 3

Перед:
- Книга 4
```

Без preview не виконувати bulk insert.

## `previous_book_paused`

CTA відкриває книгу або чинний resume dialog.

Не змінювати status прямо з sidebar, якщо backend/UX не має готової атомарної mutation.

## `current_reading_ahead_of_order`

Відкрити попередню книгу. Не ставити поточну книгу на паузу автоматично.

## Ownership flows

### `NONE`

Використати чинний confirmation/mutation для `WANT_TO_BUY`. Після success інвалідовувати issue query.

### `WANT_TO_BUY`

Перейти до purchase flow.

### `IN_TRANSIT`

Перейти до order details.

### `LENT_TO`

Перейти до loan details.

## «Залишити як є»

Показати невелике підтвердження, якщо це відповідає UX проєкту. Після ignore:

- прибрати issue з блока;
- оновити count;
- показати snackbar;
- не змінювати чергу.

Текст snackbar:

```text
Це попередження приховано для поточного порядку
```

## «Не перевіряти цю серію»

Обов’язкова confirmation modal:

```text
Вимкнути перевірку порядку?

BookNest більше не показуватиме попередження для цієї серії.
Увімкнути перевірку можна в налаштуваннях серії.
```

Кнопки:

```text
Скасувати
Не перевіряти серію
```

Після success:

- прибрати issue;
- інвалідовувати query;
- показати snackbar;
- у налаштуваннях серії відобразити toggle для повторного ввімкнення.

## Після успішного queue fix

1. Закрити модалку.
2. Показати snackbar `Порядок серії виправлено`.
3. Інвалідовувати/оновити:
   - queue list;
   - positions;
   - queue counts;
   - series-order issues;
   - блоки «Потребують уваги»;
   - current reading, якщо релевантно.
4. Не виконувати full page reload.
5. Перемістити focus на змінену книгу або success message.
